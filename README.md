# Sesc Tocantins — Tour Virtual

Portal de visitas virtuais das nove unidades do Sesc Tocantins.

Site: https://mgtour360graus.github.io/Sesc-tocantins-tour-virtual/

As unidades abrem seus tours em uma janela de 90% da tela. Feche a janela para selecionar outra unidade.

Inclui mapa interativo com dados do OpenStreetMap, cinco redes sociais oficiais, site institucional e telefone geral (63) 3219-9100.

As miniaturas são as capas originais dos tours. Esta página conecta as publicações existentes, preservando seus projetos.
